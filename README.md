# Prompt Forge · 本地提示词与 LoRA 库

> 一个**跑在自己电脑上**的提示词 / LoRA / 底模资料库：离线可搜、能组合、能直接复制进 ComfyUI。
> 不需要注册、不需要账号、不联网也能用；你自己的收藏和作品只在你这台电脑上。

## ⬇️ 下载

**[点这里下载最新版（Windows 64 位）](../../releases/latest)**

- 压缩包约 56 MB，解开即用，**不需要安装、不需要 Python**
- 支持 Windows 10 / 11（64 位）

## 三步开始用

1. 把下载到的 `PromptForge-x.x.x-win64.zip` **解压**到任意目录（路径别带特殊符号就行）
2. 双击里面的 **`启动.bat`**
3. 浏览器会自动打开界面；如果没打开，把黑窗口里显示的那个 `http://127.0.0.1:8765/?k=...` 地址贴进浏览器

> 那个黑色命令行窗口**就是程序本体**，关掉它 = 退出程序。下次再双击 `启动.bat` 即可。
> `?k=` 后面的令牌每次启动都会变，用黑窗口里最新给的那个地址。

## 数据放在哪

- 程序目录：解压出来的那个文件夹（可以随时替换升级）
- **你的数据**：`C:\Users\你的用户名\AppData\Local\PromptForge\user-data`
  （数据库、收藏、笔记、私有作品都在这里；升级程序不会动它）
- 想连数据一起搬走：把上面这个 `user-data` 文件夹复制走即可

## 内容更新

公开内容（提示词 / LoRA / 案例 / 标签）通过本仓库更新：

1. 界面右上角 **检查更新** → 有新内容会告诉你差多少文件
2. 点 **一键更新**，只下载变化的文件，不动你的个人数据

> 本仓库的 `manifest.json` + `data/` + 图片就是这个更新源；请不要改名或删除文件。
> 如果界面里内容明显是旧的（比如分区只有几个），到「设置与更新 → 重建内容库」点一下即可。

## 隐私

- 程序只监听 `127.0.0.1`，每次启动生成随机访问令牌，外部访问不了
- 不上传、不统计、不联网校验（除非你点「检查更新」）
- 详见压缩包内 `SECURITY_AND_PRIVACY.md`
